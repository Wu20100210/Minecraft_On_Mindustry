# MC On Mindustry

把 Minecraft 的方块、工具、武器、矿石、树木、生物和红石科技做进 **Mindustry v160** 的 Kotlin 模组。

新增一颗可登陆的星球「方块世界」，拥有独立的出生区域、森林、下界区块、五种生物群系、核心、科技树、仓库、物流系统与兵工厂。

当前内容规模：**63 个方块、46 个物品、9 个单位、237 张自动生成贴图**，中英文 bundle 齐全。

---

## 内容总览

### 物品与矿产

| 类别 | 内容 |
| --- | --- |
| 木材 | 原木、木板 |
| 石料 | 圆石、石头、沙子 |
| 矿石 | 煤炭、铜矿石、铁矿石、金矿石、钻石、红石、下界残骸、下界合金碎片 |
| 金属 | 铜锭、铁锭、金锭、下界合金锭 |
| 其他 | 玻璃、羊毛、皮革、鸡蛋、猪肉 |

矿石以地表覆盖层生成，用不同等级的矿井开采（硬度 1–5）：

- 矿井（2 级）：圆石、煤炭、铜矿石、红石
- 深层矿井（3 级）：铁矿、金矿
- 钻石矿井（4 级）：钻石
- 下界矿井（5 级）：下界残骸

树木是**实心的矿物墙**（StaticWall），带有自定义 `wood` 属性；把「伐木场」贴着树放置即可自动采集原木。

### 工具升级路线

斧头、镐子、锄头各有 6 个等级：

> 木 → 石 → 铁 → 金 → 钻石 → 下界合金

工具由对应等级的「工匠台」一次产出（斧 + 镐 + 锄 + 剑），并作为机器的建造成本，例如：

- 矿井需要木镐
- 伐木场需要木斧
- 鸡舍/牛舍/羊圈/猪圈需要对应等级的锄头

### 武器升级路线

**近战武器 → 只对地炮台**（射程短、伤害高、消耗红石）：

> 木剑 → 石剑 → 铁剑 → 金剑 → 钻石剑 → 下界合金剑

**远程武器 → 只对空炮台**：

> 弓 → 弩 → 三叉戟

炮台全部以红石为弹药，与红石矿业/电力形成同一条产业链。

### 红石与电力

| MC 方块 | Mindustry 中的功能 |
| --- | --- |
| 红石中继器 | 电力中枢（大范围电力节点） |
| 红石块 | 电池（储存 4000 电力） |
| 红石火把 | 发电机（燃烧红石发电） |

### 生产链

- 工作台：原木 → 木板
- 熔炉（铜/铁/金/玻璃/石头）：矿石 + 煤炭 → 锭/玻璃/石头
- 高炉：下界残骸 + 煤炭 → 下界合金碎片
- 锻造炉：下界合金碎片 + 金锭 + 煤炭 → 下界合金锭
- 伐木场：树木墙 → 原木
- 鸡舍 / 牛舍 / 羊圈 / 猪圈：消耗电力，产出鸡蛋 / 皮革 / 羊毛 / 猪肉
- 仓库：大容量物品存储；**贴着核心时会并入核心容量**（实测 4000 → 5200）

### 物流系统

| 方块 | 功能 |
| --- | --- |
| 传送带 | 木制传送带，把物品运向下一格，支持转弯/汇合 |
| 漏斗 | 从相邻仓库或核心取出物品并送入前方 |
| 路由器 | 把物品平均分配到周围三格 |
| 分类器 | 只放行指定物品 |
| 交叉器 | 让两条物品线路交叉通过 |
| 物流节点 | 与另一个物流节点建立链接，最远 8 格远距离运输 |

物流方块可以配合仓库、核心和各种工厂搭出完整的“核心 → 仓库 → 工厂 → 炮台”供料网络。

### 兵工厂与玩家单位

「兵工厂」（3×3）消耗电力与资源制造玩家单位：

- 雪傀儡：远程投掷雪球，可打空中目标
- 铁傀儡：高血量、高护甲的重型近战单位

兵工厂有两个生产计划，可在建筑配置界面切换；单位会计入玩家单位上限。

### 敌对生物（单位）

僵尸、骷髅、苦力怕、蜘蛛、末影人、幻翼、恶魂。

- 会随波次从地图边缘的刷怪点进攻
- 骷髅射箭、恶魂火球，幻翼/恶魂是空中单位（需要只对空炮台应对）
- 苦力怕死亡时爆炸

### 星球与核心

- 星球「方块世界」：五种生物群系——平原、森林、沙漠、山地、下界
- **地形采用 Erekir 风格**：
  - 整张地图默认是实心岩壁，用 Ridged 噪声挖出峡谷与空腔
  - `cells` / `distort` / `median` / `inverseFloodFill` 做地形塑形
  - 出生点在一端，敌巢刷怪点在另一端，中间用 A* `pathfind` + `brush` 开出一条通道
  - 峡谷底部有草地、水潭、树木和花草，矿石沿通道两侧分布
- 462×462 地图实测：约 52% 可通行空地 / 48% 岩壁，含 3.8% 水面、1.9% 树木、14% 矿石
- 3 个区块：初级区域（出生点）、森林、下界
- 3 个核心：初级核心（3×3）、中级核心（4×4）、最终核心（5×5）
- 科技树结构按 `MC_On_Mindustry.drawio` 重排：初级核心在顶部，**工作台**作为总枢纽，向下分出多条平行建筑链：

```
初级核心
├─ 中级核心 → 最终核心
├─ 初级区域 → 森林 → 下界
└─ 工作台
   ├─ 木工台 → 石匠台 → 铁匠台 → 金匠台 → 钻石匠台 → 合金匠台
   ├─ 伐木场
   ├─ 红石中继器 → 红石火把 / 红石块
   ├─ 鸡舍 → 牛舍 → 羊圈 → 猪圈
   ├─ 兵工厂
   ├─ 木剑炮台 → 石剑炮台 → 铁剑炮台 → 金剑炮台 → 钻石剑炮台 → 合金剑炮台
   │  └─ 弓炮台 → 弩炮台 → 三叉戟炮台
   ├─ 矿井 → 深层矿井 → 钻石矿井 → 下界矿井
   ├─ 熔炉·石头 → 熔炉·铜 → 熔炉·铁 → 熔炉·金 → 高炉 → 锻造炉
   │  └─ 熔炉·玻璃
   └─ 传送带 → 物流节点 / 路由器 → 交叉器 → 分类器 / 仓库
```

- **所有方块的研发花费统一为建造花费的 3 倍**（例如工作台：建造 40 原木 + 20 圆石，研发 120 原木 + 60 圆石）

## 玩法流程

1. 在星球界面选择「方块世界 → 初级区域」降落。
2. 用初始资源建「木工台」，产出木镐/木斧/木锄/木剑。
3. 建「伐木场」砍树得到原木，建「工作台」把原木加工成木板。
4. 建「矿井」开采圆石、煤炭、铜矿与红石。
5. 建「熔炉·铜」与「熔炉·铁」把矿石炼成锭。
6. 建「传送带 / 路由器 / 漏斗」把矿石送进熔炉，把锭送回核心。
7. 建「红石中继器」「红石火把」「红石块」组成电力网络，为鸡舍/牛舍/兵工厂供电。
8. 建「兵工厂」生产雪傀儡与铁傀儡，配合剑炮台守家。
9. 按科技树升级工匠台、矿井、武器炮台，最终前往森林与下界，获取钻石与下界合金。
10. 抵御波次，达到捕获波数后占领区块。

## 构建

需要 JDK 17+。首次构建会从 GitHub 下载 Mindustry 依赖。

```bash
# Windows
gradlew.bat jar

# Linux / macOS
./gradlew jar
```

产物：`build/libs/MC_On_MindustryDesktop.jar`，放入 Mindustry 的 `mods/` 目录即可。

Android 版本可使用 `gradlew deploy`（需要设置 `ANDROID_HOME` 与 `d8`）。

### 资源生成脚本

`tools/` 下有两个 Python 脚本，用于从 `素材/` 生成全部贴图与本地化文件：

```bash
python tools/gen_sprites.py    # assets/sprites/*.png + assets/icon.png
python tools/gen_bundles.py    # assets/bundles/bundle*.properties
```

修改内容名称或新增方块/物品后，记得同步更新这两个脚本中的名称表。

## 开发说明

- 模组内部名为 `MC-On-Mindustry`，Mindustry 会自动给代码中创建的内容加上 `mc-on-mindustry-` 前缀。因此：
  - 贴图文件名保持短名（如 `mujianpaotai.png`），打包时会自动加前缀；
  - 本地化键需要带前缀，例如 `block.mc-on-mindustry-gongzuotai.name`；
  - Kotlin 中直接使用短名即可，例如 `Item("yuanmu")`。
- 贴图尺寸：1×1 方块 32×32，2×2 方块 64×64，3×3 方块 96×96，3×3 核心 96×96，4×4 核心 128×128，5×5 核心 160×160。
- 炮台需要 `名字.png`（旋转的炮管）、`名字-base.png`（底座），可选 `名字-preview.png`、`名字-heat.png`。
- 传送带需要 `名字-<0..6>-<0..3>.png` 共 28 张自动连接贴图（`Conveyor` 的 `@Load("@-#1-#2", lengths={7,4})`），另外保留一张 `名字.png` 作为图标。
- 漏斗需要 `名字-center.png`；分类器需要 `名字-cross.png`；物流节点需要 `名字-end/-bridge/-arrow`；兵工厂需要 `名字-top/-out/-in`。
- 树木是 `StaticWall`，靠 `attributes.set(Environment.wood, 1f)` 被「伐木场」（WallCrafter）识别。
- 地图噪声采用 Erekir 行星生成器的写法：`rawHeight` + `rawTemp` 选地表，默认整图岩壁，Ridged 噪声挖空腔；再用 `cells/distort/median/inverseFloodFill` 塑形，并用 `pathfind` 从出生点向敌巢开路。
- 波次在星球的 `ruleSetter` 中设置，避免读档时被原版波次覆盖。
- 仓库 `coreMerge = true` 时才会并入相邻核心的 `storageCapacity`，这是修复“仓库贴核心不涨容量”的关键。
